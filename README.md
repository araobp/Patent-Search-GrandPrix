## 構成要素キーワード抽出

あなたはプロの特許サーチャーです。
添付される内容で特許検索式を構築しようとしています。
主要な構成要素をキーワードとして抽出し、その同義語および上位概念・関連語を横軸に配置して、セル内に日本語の同義語および上位概念・関連語を網羅的に抽出して表形式で出力してください。

## 検索マトリクス生成

あなたはプロの特許サーチャーです。添付された特許公報に基づき、特許検索式を構築するための「特許検索マトリクス」をMarkdownの表形式で作成してください。

【出力要件】
1. 軸の配置：
   - 横軸：主要な構成要素（例：触覚提示、MRF駆動、変位量検出・変換、マルチモーダルなど、公報の技術内容から抽出）
   - 縦軸：調査観点（「キーワード・同義語」「FI」「FI（要素横断）」「Fターム」「Fターム（要素横断）」「Fターム（全体横断）」）
2. 複数要素にまたがる横断項目の表現：
   - 複数の構成要素にまたがるFIやFターム（要素横断・全体横断）については、2つ目以降の該当セルに「左に同じ」と記載してください。
3. 表のスタイリングと制約：
   - 色情報、背景色、HTMLタグなどの余計な装飾や装飾的記述は一切省き、標準的なMarkdownの表形式のみで出力してください。
   - 全角・半角文字の混在による表示崩れを防ぎ、プレーンテキストのMarkdownとして美しく整えられた形式にしてください。

## 論理式生成

あなたはプロの特許サーチャーであり、特許検索競技大会の受験者です。
先ほど作成した「特許検索マトリクス」の結果を用いて、J-PlatPat（特許・実用新案テキスト検索）にそのまま入力できる検索式（論理式）を、以下の【出力フォーマット】に従って作成してください。

【検索式構築の方針】
大会の採点基準を意識し、以下の3つのアプローチで段階的に絞り込むストーリーを作成してください。
1. アプローチA（分類主導・広め）：要素横断のFI/Fタームを主軸にし、キーワードで補正する（再現率重視）。
2. アプローチB（ピンポイント・中程度）：各構成要素の個別FI/FタームをANDで掛け合わせる（バランス重視）。
3. アプローチC（キーワード補強・深掘り）：分類でカバーしきれない固有技術（MRFや初期変位など）をキーワードのANDで狙い撃つ（適合率重視）。

【J-PlatPatの構文ルール】
- 論理演算子は半角大文字で「OR」「AND」「NOT」を使用する。
- 括弧は半角「( )」を使用する。
- キーワードの検索項目は「/TX」（全文）または「/BI」（書誌・要約・請求の範囲）を使用する。
- FIは「/FI」、Fタームは「/FT」を付与する（例：G06F3/01/FI, 5E555AA08/FT）。
- Fタームの「左に同じ」で横断していたものは、該当する構成要素のキーワードや分類のOR群に対してANDで掛け合わせる形に展開する。

【出力フォーマット】
■論理式番号：[例：L001]
■方針：[この論理式が何を狙っているステップなのか、意図を2〜3文で簡潔に説明]
■論理式：[J-PlatPatにペースト可能な式]

（※上記のセットを、アプローチA〜Cでそれぞれ数パターン、計5〜6式程度生成してください）
