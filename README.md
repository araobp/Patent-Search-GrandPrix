# Gemini向けプロンプト集

バイブルは[許情報調査と検索テクニック入門　第３版](https://online-shop.jiii.or.jp/c-item-detail?ic=844)（通称、青本）だが、現職が生成AI推進の役目で仕事してる立場、エクセルではなく生成AIを活用したい。

自分なりに、青本を読んだ上で、プロンプトを組んでみた、Geminiにプロンプトを最適化させた。

論理式で検索後、各論理式毎に検索結果をCSVでダウンロードし、Google Spreadsheetへ取り込み、スクリーニング実施しながらチェック。
１次スクリーニングはタイトル、要約、図面確認でも目視確認、２次スクリーニングは要約、請求項、詳細までななめ読み、３次スクリーニングは詳細読み込み。

ここ３週間くらい、トレーングする。トレーニング中、プロンプトも改善を加えていく。

この業界もAX本格化、機械的作業はAIがアシスト、しかし、指示や判断するのは人間。判断とは、当業者としての新規性・進歩性判断のところ。幅広く現場で技術扱ってきた私の肌感覚が、この業界のAX中・AX後でも活かせるか？それを探るための良い機会。

ちなみに、生成AIは、未知の新たな分野に対しては、ハルシネーションがはなはだしい。一方、明細書要約、キーワード検出、FIやFタームへ分類のあたりはめっぽう得意。たぶん、スクリーニングもある程度はやれるはず。

仕事で数年も生成AIアプリ作り続けたが、生成AIって、思ったほどすごくなかったし、機械脳よりも生体脳の方が優れている部分も見えてきた。

## 構成要素キーワード抽出

あなたはプロの特許サーチャーです。
添付される内容で特許検索式を構築しようとしています。
主要な構成要素をキーワードとして抽出し、その同義語および上位概念・関連語を横軸に配置して、セル内に日本語の同義語および上位概念・関連語を網羅的に抽出して表形式で出力してください。

## 検索マトリクス生成

あなたはプロの特許サーチャーです。添付された特許公報に基づき、特許検索式を構築するための「特許検索マトリクス」をMarkdownの表形式で作成してください。

【出力要件】
1. 軸の配置：
   - 横軸：主要な構成要素（例：触覚提示、MRF駆動、変位量検出・変換、マルチモーダルなど、公報の技術内容から抽出）
   - 縦軸：調査観点（「キーワード・同義語」「FI」「FI（要素横断）」「Fターム」「Fターム（要素横断）」「Fターム（全体横断）」）
2. 複数要素にまたがる横断項目の表現：
   - 複数の構成要素にまたがるFIやFターム（要素横断・全体横断）については、2つ目以降の該当セルに「左に同じ」と記載してください。
3. 表のスタイリングと制約：
   - 色情報、背景色、HTMLタグなどの余計な装飾や装飾的記述は一切省き、標準的なMarkdownの表形式のみで出力してください。
   - 全角・半角文字の混在による表示崩れを防ぎ、プレーンテキストのMarkdownとして美しく整えられた形式にしてください。

## 論理式生成

あなたはプロの特許サーチャーです。
先ほど作成した「特許検索マトリクス」に基づき、本願発明を無効化（または拒絶理由通知）するための「X文献（新規性否定）」および「Y文献（進歩性否定）」を戦略的に検出するJ-PlatPat用論理式を作成してください。

【論理式構築のストーリーとアプローチ】
以下の3つのステップに沿って、各アプローチの目的を明確にした論理式を生成してください。

1. 【アプローチX：X文献（主引用発明）の狙い撃ち】
   - 目的：本願の全構成要素（触覚提示＋MRF駆動＋変位量変換＋マルチモーダル）を1文献で網羅している新規性否定の文献をピンポイントで抽出する。
   - 構成：全要素の個別分類（FI/Fターム）のAND掛け合わせ、および主要キーワードの厳格なAND結合。

2. 【アプローチY1：Y文献（副引用発明：デバイス・駆動側）の抽出】
   - 目的：触覚デバイスにおいて「MRF（機能性流体）を用いて粘性・駆動制御を行うこと」の容易性（周知・慣用技術）を立証する文献を抽出する。
   - 構成：触覚×駆動の横断分類（5E555CB59等）に流体キーワードを結合し、UI・マルチモーダル側の要件はあえて外して広く集める。

3. 【アプローチY2：Y文献（副引用発明：UI・制御プログラム側）の抽出】
   - 目的：「操作入力（変位量）に応じて画像や音声を連動・出力させること」の容易性を立証する文献を抽出する。
   - 構成：変位×表示音響制御の横断分類（5E555DA24等）やUI制御FI（G06F3/048）を活用し、アクチュエータ（MRF）の種別は不問として抽出する。

【J-PlatPatの構文ルール】
- 論理演算子は半角大文字で「OR」「AND」「NOT」を使用する。
- 括弧は半角「( )」を使用する。
- キーワードの検索項目は「/TX」（全文）または「/BI」（書誌・要約・請求の範囲）を使用する。
- FIは「/FI」、Fタームは「/FT」を付与する（例：G06F3/01/FI, 5E555AA08/FT）。

【出力フォーマット】
■論理式番号：[例：L001]
■狙い（X文献／Y文献の別）：[例：X文献狙い（新規性否定）]
■方針：[審査官・サーチャー視点での戦略的意図を2〜3文で説明]
■論理式：[J-PlatPatにペースト可能な式]

（※上記のアプローチX, Y1, Y2について、それぞれ1〜2パターンずつ計4〜5式作成してください）
